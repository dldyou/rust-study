# rust-grammer

기본적인 러스트 문법을 익히며 예제들을 정리한 레포지토리 입니다.

[Just Do Rust - 러스트 기초부터 고급까지](https://wikidocs.net/book/16747)를 기반으로 작성하였습니다.

해당 레포지토리는 아래의 목차로 구성되어 있습니다.

| 목차 | 내용                                                        |
| ---- | ----------------------------------------------------------- |
| 3    | [초급: Rust 기본 문법](https://wikidocs.net/262252)         |
| 4    | [중급: Rust 특징](https://wikidocs.net/262261)              |
| 5    | [고급 1: Rust 응용](https://wikidocs.net/262268)            |
| 6    | [고급 2: 외부 라이브러리 이용](https://wikidocs.net/306830) |

각 목차는 소목차를 포함하고 있으며, `pA_B.rs` 형식으로 3장의 1번째 소목차는 `p3_1.rs`로 작성되어 있습니다.

소목차에 포함된 예제는 다음과 같이 실행할 수 있습니다.

```bash
cd rust-grammer
cargo run A.B
```
