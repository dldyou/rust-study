# 탄막 시뮬레이션 테스트 환경 설계

## 목적

탄막 패턴 라이브러리를 만들기 전에 Rust 단위 테스트 작성법을 연습할 수 있는
작고 결정적인 시뮬레이션 환경을 만든다.

## 범위

- 2차원 위치와 속도를 표현한다.
- 탄환을 생성하고 보관한다.
- 시간 간격을 받아 탄환 위치를 갱신한다.
- 나중에 패턴 생성 함수를 추가할 수 있는 경계를 만든다.
- 외부 게임 엔진 없이 `cargo test`로 검증한다.

## 범위에 넣지 않는 것

- 화면 렌더링
- 키보드·마우스 입력
- 실시간 루프와 시스템 시계
- 난수 기반 패턴
- 충돌 판정, 삭제, 수명 관리
- ECS나 외부 프레임워크

## 최소 구조

기존 `src/dangan.rs` 하나에서 시작한다.

```text
Vec2
 ├─ x: f32
 └─ y: f32

Bullet
 ├─ position: Vec2
 └─ velocity: Vec2

World
 └─ bullets: Vec<Bullet>
```

`World::tick(dt)`는 각 탄환에 대해 다음을 수행하는 최소 동작으로 둔다.

```text
position += velocity * dt
```

패턴 생성 함수는 처음부터 완성하지 않고, `World`에 탄환을 넣는 방식으로 확장할
수 있도록 자리만 둔다.

## 테스트 우선순위

1. 기본 자료구조를 만들 수 있다.
2. 초기 탄환 위치와 속도를 보존한다.
3. 한 번의 `tick` 후 위치가 예상값으로 변한다.
4. 여러 번의 `tick` 결과가 누적된다.
5. 같은 입력은 언제나 같은 결과를 만든다.

각 테스트는 하나의 동작만 검증하고, 부동소수점 비교에는 작은 허용 오차를
사용한다. 테스트가 먼저 실패하는 것을 확인한 뒤 사용자가 직접 구현한다.

## 파일 변경 계획

- `src/dangan.rs`: 자료구조, 메서드 시그니처, 테스트 골격
- `src/main.rs`: 현재 모듈 선언을 유지

새 의존성은 추가하지 않는다.
